# ブログ毎週の流れ（案・2026-11-25）

目的: 週3本（月・水・金 朝8時公開）を、あっきーさんの承認は週1回・約5分で回す。読み手は独立系美容クリニックの院長。
書き方の正本は `content/BLOG_WRITING_GUIDE.md`、置き場と下書きの仕組みは `content/README.md`。

## 流れ

| いつ | 誰が | 何をする |
|---|---|---|
| 毎週土曜 朝（案: 9:00） | クラの定時実行 | Omi の直近2〜3週（期間付き）から、あっきーさん本人が話した実体験・判断の話を3つ選ぶ。既存記事（content/blog/*.md の title と description）と被らないか照らす |
| 同 | 同 | 作業場（wt_new.sh）で枝 `blog/draft-<翌週月曜の日付>-week` を作り、`content/blog/<slug>.md` を3本、`draft: true` ＋ `publishAt`（月・水・金 08:00 JST）で置く。frontmatter の `sources` に Omi の日付と原文の要所を控える。main には出さず、枝を push して Vercel の Preview（draft も見える・noindex）を作る |
| 同 | 同 | 承認を1画面で頼む（非公開アーティファクト）。3本の題名・一行要旨・ネタの Omi の日付と原文の要所・Preview の URL を並べ、「3本OK／この本だけ直す／この本は見送り」だけ選べる形 |
| 土〜日 | あっきーさん | 約5分で選ぶ。直したい所は「どこを・どう」だけ言う（Voice・主張は Claude が勝手に変えない） |
| 承認後（日曜夜まで） | クラ（司令塔の承認を受けて） | OK の本だけ `draft: true` を外し、`publishAt` を確認、過去記事への逆リンクと related を整える。`npm run build` と表示確認（スマホ幅）→ main に入れて push（Vercel が自動デプロイ。publishAt まで本番には出ない）。見送りの本は枝に残し、ネタ帳へ戻す |
| 月・水・金 08:00 | hauoli-admin の予約 tick（5分毎） | 公開時刻を過ぎたら Deploy Hook で本番ビルド。ここは既存の仕組みのまま |
| 公開日の夕方 | クラ | 本番の URL・sitemap・feed を見て、公開できたかを1行で。SNS 配信（sns-post）は公開日が古い順の決まりに従い、あっきーさんの指示があれば |

## 守る線
- 下書きの間は公開・予約・SNS 配信をしない。main へ入れるのは承認後だけ
- 本文に出さない: Léâme・JAM の社内の数字、クライアント名、店舗名、スタッフ名
- あっきーさんが話していない体験談・数字を足さない。録音に出た AI の合成音声（声のテスト）の台本は、本人の発言として使わない（11/19 の録音で実際にあった）
- リールの語り（叱らない）の決まりとブログの語りは別。ただしクリニックの話は実体験の場面だけ（decisions/hauoli-cmo.md）
- 週の途中でネタが足りなければ、無理に3本にせず2本で出す（質を落とさない）
